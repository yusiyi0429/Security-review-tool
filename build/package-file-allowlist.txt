# package-file-allowlist.txt
# ===========================
# Defines the set of files permitted in the portable Windows release ZIP.
# One allowed pattern per line. Patterns use forward-slash separators.
# Lines starting with '#' are comments. Blank lines are ignored.
#
# Patterns:
#   Exact name:       SecurityReviewTool.exe        (matches root-level file only)
#   Directory prefix: worker/                       (matches any file under worker/)
#   Wildcard:         *.dll                         (matches root-level .dll files)
#
# Forbidden (enforced by the verifier, not listed here):
#   .pdb, .xml compiler docs, test assemblies, corpus, source, .git,
#   workbook, .db/.sqlite/.sqlite3, WAL/SHM, keyring, config,
#   credential, log, temp, report, private key, crash dump.
